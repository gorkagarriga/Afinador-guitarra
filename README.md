# Afinador de guitarra española

Dos afinadores web gratuitos para guitarra española.

- **Afinador completo**, con aguja, notas de referencia y metrónomo: https://gorkagarriga.github.io/Afinador-guitarra/
- **Afina**, el afinador mínimo (se puede añadir a la pantalla de inicio): https://gorkagarriga.github.io/Afinador-guitarra/afina/
